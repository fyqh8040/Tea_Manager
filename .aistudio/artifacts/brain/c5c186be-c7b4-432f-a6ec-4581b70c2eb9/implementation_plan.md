# 茶韵典藏 · AI 智能茶席顾问与知识引擎实施方案

为「茶韵典藏」系统注入基于 Gemini 的专业茶学与器物智能化能力，打造集“智能侍茶选配、感官风味雷达生成、图片识别快速录入”于一体的私房茶室数字管家。

> [!IMPORTANT]
> **已确认的产品决策与设计方向（基于澄清答复）：**
> 1. **全套融合核心场景**：覆盖“智能侍茶对话”、“品饮笔记与风味雷达推算”、“照片/图片识别快速录入”三大核心能力。
> 2. **交互形态**：采用全局右下角沉浸式“浮动茶席顾问”（可折叠/展开多轮对话，含快捷提示词抽屉），并在“添加藏品”及“品记录入”弹窗中内嵌一键式“AI 智能补全/风味推算”快捷动作。
> 3. **数据底座深度关联**：AI 侍茶师实时挂载用户本地现存的茶叶库存（年份、类别、茶性）与茶壶器物（容量、泥料、适茶性），支持精准的“今日宜饮什么茶”、“用我现有的哪把壶配这款老白茶”等个性化决策。

## 1. Overview & Core Concept

### What It Does
- **私房茶席侍茶师（Tea Sommelier Advisor）**：结合气节时令、用户心情、当日餐食及真实藏品库存，提供选茶建议、器皿配对、投茶量、水温与冲泡节拍指导。
- **感官品记与风味雷达 AI 生成（Sensory Profiler）**：茶友仅需随性写下几句喝茶感受（如“带有幽幽兰花香，回甘清冽生津，喉韵深但略带一点焙火气”），AI 即可自动推导 `甘 (Sweetness)`、`醇 (Mellowness)`、`香 (Aroma)`、`涩 (Astringency)`、`韵 (Aftertaste)` 五维风味雷达评分，并润色出雅致的品茗志。
- **识茶识器智能录入（Smart Asset Extractor）**：支持上传茶饼包装纸、茶盒标签、茶叶条索或紫砂壶底款/证书照片，AI 自动提取品名、年份、茶类、产地、泥料、容量并填入表单。

### Target Audience & Persona
- 热爱茶道与雅致生活的茶友、紫砂壶收藏家。希望省去繁琐的数据录入，在每一次开汤品饮时获得专业指导与仪式感。

### Key Value
- **从“静态记账”升级为“动态茶事生活伴侣”**：让沉睡的库存数据成为与 AI 互动的鲜活知识底座。

## 2. User Experience & Visual Design

### 视觉语言与东方雅致美学
- **设计基调**：延续宋代汝窑与水墨竹青风格，采用浅宣纸色底色（`#FDFBF7`）、竹青主色（`#4A7C6F`）、朱砂红印章点缀（`#9A3412`）与极细墨线边框（`border-stone-200`）。
- **零胶囊设计原则（Zero-Pill Discipline）**：元数据（年份、泥料、品类）采用纯文本与中置点（`·`）排版，拒绝廉价高饱和药丸徽章。
- **字体排印**：标题与诗意评语采用 `Noto Serif SC`（宋体/仿宋），系统提示与数字参数采用清晰的 `Inter` 与等宽字体。

### 核心用户流程

#### 流程一：全局浮动侍茶师（Floating Tea Sommelier）
1. 页面右下角常驻雅致的“侍茶小印”浮动悬浮球（带茶气缭绕微动效与未读灵感提示）。
2. 点击展开东方茶室风格对话抽屉（宽度 400px，高度自适应，支持全屏/吸顶收起）：
   - 顶部提供快捷场景卡片：“今日宜饮”、“选茶配壶”、“冲泡指津”、“库存盘点洞察”。
   - 对话过程支持流式打字机渲染，当推荐具体藏品时，卡片内高亮显示该藏品快捷卡，点击可直接打开对应藏品详情。

#### 流程二：品饮笔记中的风味推导（Sensory Profiling）
1. 用户在“品饮随笔/笔记”弹窗中输入自由文本。
2. 点击【AI 解析风味雷达】：
   - AI 提取文本中的香气特征与滋味感，自动计算 0~100 的五维分值并实时渲染到五边形风味雷达图上。
   - 提供【AI 润色为雅致茶志】选项，一键生成具有文学美感的品鉴心得。

#### 流程三：智能拍照识图录入（Visual Ingestion）
1. 在“添加茶品”或“添加茶器”弹窗中，点击【AI 识图填单】。
2. 选择本地图片或粘贴图片外链，AI 迅速结构化识别并在表单对应输入框中呈现高亮预览，用户核对后一键确认填充。

## 3. Key Product Decisions & Trade-Offs

### 决策一：模型选型与 API 架构
- **选型**：采用 Google Gemini 最新兼顾速度与多模态能力的 `gemini-2.5-flash`。
- **架构方案**：采用 Node.js 服务端代理路由（`/api/ai/*`），严禁在前端直接暴露 `GEMINI_API_KEY`：
  - 本地与全栈运行时通过 Node.js Express 代理请求。
  - Vercel 部署环境自动由 Serverless 函数承载。
- **备选考量**：若未配置 API Key，前端提供优雅的提示与模拟示例预览，确保离线与零配置状态下不发生白屏或抛出未捕获错误。

### 决策二：上下文注入与私房藏品底座挂载
- **方案**：采用轻量级客户端上下文提炼。在向 `/api/ai/chat` 发送请求时，系统自动将当前用户的茶叶精简索引（品名、茶类、年份、余量）与茶器列表（品名、材质、容量）压缩为紧凑的 System Prompt 知识上下文（不超过 3KB），无需复杂且缓慢的向量检索，兼具零延迟与高准确度。

### 数据结构扩展（新增 AI 辅助状态）
- 扩展 `src/types/tea.ts`，定义 AI 对话消息格式 `AiMessage`，以及风味解析响应结构 `SensoryAiResponse`。
- 新增组件与服务：
  - `src/components/ai/FloatingSommelier.tsx`：浮动侍茶师面板。
  - `src/components/ai/SensoryRadarAssistant.tsx`：品记风味辅助工具。
  - `src/components/ai/ImageTeaScannerModal.tsx`：图片识别录入弹窗。
  - `src/services/aiService.ts`：前端与后端 AI 接口的标准化通信层。
  - `server.ts` 及 `/api/ai/*.js`：安全代理端点。

### 验收与验证标准
1. 对话顺畅自然，能准确识别用户现存的真实茶叶与茶器并提供配搭建议。
2. 品饮风味雷达可从自然语言描述中正确提取 5 维数据并渲染图表。
3. 图片识别支持单图上传并自动填入茶叶/茶器表单。
4. 全程符合 WCAG 无障碍规范与东方宋瓷雅致视觉风格。
